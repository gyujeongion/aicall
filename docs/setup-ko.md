# 처음 설정 안내

AI 통화는 맥에 들어 있는 전화 앱으로, 내 아이폰 번호를 써서 전화를 겁니다. 설치는 명령 한 줄로 끝나는데, 아이폰 연결과 권한은 직접 켜야 합니다. 처음이면 15분쯤 잡으세요.

## 준비물

- 애플 실리콘 맥 + macOS 27, 언어는 한국어
  (전화 앱 단추를 한국어 이름으로 찾습니다. 영어로 쓰는 맥에서는 아직 안 걸립니다.)
- 맥과 같은 애플 계정으로 로그인한 아이폰
- OpenAI API 키 — [platform.openai.com](https://platform.openai.com/api-keys)에서 만들고, 결제 수단을 등록해 둡니다
- [홈브루](https://brew.sh)

## 1. 아이폰 전화를 맥에 연결

1. 아이폰: **설정 > 앱 > 전화 > 다른 기기에서 통화 허용**을 켜고, 목록에서 이 맥을 켭니다.
2. 맥: **전화** 앱을 열고 설정에서 **iPhone 통화**를 켭니다. 코드가 뜨면 아이폰에 입력합니다.
3. 전화 앱으로 가족이나 내 다른 번호에 한 번 걸어 봅니다. 상대 화면에 내 아이폰 번호가 뜨면 됐습니다.

여기서 안 되면 AI 통화도 안 됩니다. 이 단계부터 확인하세요.

## 2. 설치

터미널에 붙여 넣습니다.

```bash
curl -fsSL https://raw.githubusercontent.com/gyujeongion/aicall/main/install.sh | zsh
```

- 개발자 도구가 없으면 설치 창이 먼저 뜹니다. 설치가 끝나면 같은 명령을 한 번 더 실행하세요.
- 중간에 맥 비밀번호를 한 번 묻습니다. AI 목소리를 전화에 넣는 가상 오디오 장치(AICall Mic / Speaker)를 설치할 때 씁니다.
- 끝나면 **AI 통화** 앱이 열립니다.

## 3. 앱의 첫 설정 화면

빠진 항목이 목록으로 나옵니다. 세 가지는 이 화면에서 바로 넣습니다.

- **OpenAI API 키** — 이 맥의 `~/.config/aicall/.env`에만 저장됩니다.
- **전화에서 밝힐 내 이름** — AI가 "○○○ 님 대신 전화드린 AI 비서입니다"라고 소개할 때 씁니다.
- **내 휴대폰 번호** — 어떤 형식으로 써도 됩니다. 자동 안내가 "지금 거신 번호로 등록할까요?"라고 물을 때 맞는지 확인하는 데 씁니다.

## 4. 권한

**시스템 설정 > 개인정보 보호 및 보안**에서 *AI 통화*를 켭니다. 처음 쓸 때 권한 창이 차례로 뜹니다. 놓쳤으면 여기서 켜세요.

| 항목 | 쓰는 곳 |
|---|---|
| 기기 제어 및 데이터 접근 | 전화 앱에 번호 넣기, 걸기, 키패드 누르기, 끊기 |
| 화면 및 시스템 오디오 녹음 → 시스템 오디오 녹음만 | 상대 목소리 듣기 |
| 마이크 | 연습 모드 (전화 없이 맥 마이크로 대화) |
| 연락처 (선택) | 이름으로 걸기 |

## 5. 시험

전화 없이 먼저 해 봅니다. 맥 마이크와 스피커로 대화하고, 내가 식당 직원 역할을 맡습니다.

```bash
aicall call 0 "식당에 전화했다고 치고 토요일 저녁 7시에 두 명 예약을 잡아 줘" --practice --follow
```

그다음 실제 전화는 가족이나 내 다른 번호에 먼저 걸어 보세요. 막히면 `aicall doctor`가 빠진 것과 고치는 명령을 알려 줍니다.

## 알아 둘 것

- **업데이트**: 설치 명령을 다시 실행하면 됩니다. 설치할 때 이 맥 전용 서명을 한 번 만들어 두고 매번 같은 서명으로 빌드해서 권한은 그대로 남습니다. 혹시 풀렸으면 4번만 다시 켜세요.
- **비용**: OpenAI 사용량만큼 나갑니다. 통화 시간이 길수록 늘어납니다.
- **기록**: 통화마다 받아쓴 기록이 `~/Library/Application Support/AICall/calls/`에 남습니다. 녹음은 기본으로 꺼져 있습니다.
- **AI가 하지 않는 것**: 주민번호·생년월일·카드·계좌·비밀번호는 말하지도 누르지도 않습니다. 상대가 그런 걸 물으면 앱에 알림이 뜹니다. 아이폰 통화 화면에서 직접 누르세요. 결제와 계약도 하지 않습니다.
